# 写作类模板

适用：写邮件、文案、通知、总结、翻译、改写。产出是一篇文字时用这套。

## 模板
```
你是一位{角色}。
任务：{任务句，动词开头}。
背景：{背景}。
材料如下：
<材料>
{材料原文}
</材料>
要求：
1. {格式与长度}
2. {语气}
3. {禁忌逐条列}
参考例子（学它的结构和语气，不要抄内容）：
{例子}
交付前对照上面要求逐项自查一遍再给我。
```

## 填法
- 没有角色就删第一行，不要写「你是一位。」空句。
- 没有材料就删材料段。材料长时原文照贴，靠 `<材料>` 标记和指令分开。
- 要求只列用户真给的：格式、语气、禁忌各占条目；用户只给其中一两样，就只列一两条，不凑数。
- 没有例子就删参考例子段。
- 最后一行「交付前自查」是固定行，永远保留。
