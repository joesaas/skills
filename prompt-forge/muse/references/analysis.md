# 分析类模板

适用：文章解读、方案对比、调研汇总、给建议。产出是判断和结论时用这套。

## 模板
```
你是一位{角色}。
任务：{任务句，动词开头}。
背景：{背景}。
材料如下：
<材料>
{材料原文}
</材料>
要求：
1. 先按这几个维度拆：{维度，按任务给，如做法、成本、风险}。
2. 每个结论给出处或依据；材料里没有的明确标「材料未覆盖」，不要编。
3. {格式与长度}
4. {禁忌逐条列}
验收标准：{用户给的验收；没给时用默认：结论能逐条对回材料或依据，且不确定处都已标明}。
参考例子（学它的结构和深度，不要抄内容）：
{例子}
交付前对照要求和验收标准逐项自查一遍再给我。
```

## 填法
- 维度要按任务现场给：比方案就给成本、风险、可逆性；读文章就给主张、证据、漏洞。不要写「先一步步分析」这类口号句代替维度。
- 没有材料就删材料段，并把要求第 2 条改为：关键事实给出处链接，查不到的标「未核实」。
- 没有角色就删第一行。没有例子就删参考例子段。
- 验收标准用户跳过时填默认款，并在交付说明里标明是默认补的。
- 最后一行「交付前自查」是固定行，永远保留。
